## Benchmark-definition errors found during human oracle sanity review

Two frozen mathematics expected values are incorrect.

### `math-23` — residue-class sampling

The case selects two distinct digits in order from 1 through 9 and asks for the probability that their sum is divisible by 3.

There are `9 * 8 = 72` ordered pairs. The residue classes modulo 3 each contain three digits. A divisible-by-3 sum occurs for residue pairs `(0,0)`, `(1,2)`, and `(2,1)`:

- `(0,0)`: `3 * 2 = 6` ordered distinct pairs;
- `(1,2)`: `3 * 3 = 9`;
- `(2,1)`: `3 * 3 = 9`.

Total favorable pairs: `24`, so the probability is `24/72 = 1/3`.

The frozen v1.2.1 oracle records `1/4`, therefore the case definition is invalid.

### `math-30` — surjection counting

The case assigns five labeled balls to four labeled boxes and asks for assignments leaving no box empty.

By inclusion-exclusion:

`4^5 - C(4,1)3^5 + C(4,2)2^5 - C(4,3)1^5`

`= 1024 - 972 + 192 - 4 = 240`.

The frozen v1.2.1 oracle records `432`, therefore the case definition is invalid.
